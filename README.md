# RJGH Acquisition CRM MVP (vNext)

Local-first React + Vite acquisition CRM focused on first-deal execution.

## Run locally
```bash
npm install
npm run dev
```

## New in vNext
- Add Deal crash fix (new deal always has default scenario)
- Safe fallback dashboard calculations
- Selected deal support for Detail, Calculator, and Scenario Comparison
- Fully editable deal pipeline rows
- Editable Acquisition Calculator page
- Export JSON / Import JSON / Reset Demo Data actions

## Storage
- Uses browser localStorage key: `crmData`.
