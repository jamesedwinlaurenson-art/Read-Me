# RJGH Acquisition CRM MVP

Simple React + Vite MVP for local-first acquisition tracking and deal modelling.

## Run locally

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start dev server:
   ```bash
   npm run dev
   ```
3. Open the printed localhost URL.

## Included MVP modules
- Dashboard metrics
- Buy Box Rules editor
- Deal Pipeline tracker
- Deal Detail + scoring summary
- Scenario comparison (deal structure + investor return calculations)
- Investor contacts
- Advisor/Broker contacts
- Due diligence checklist
- Follow-up tracker
- Document tracker

## Notes
- Data persists in browser `localStorage` (`crmData`).
- Seeded with your traffic management example deal and structure scenarios.
- Built for MVP speed and easy expansion.
